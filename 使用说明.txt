使用说明
==========================================

一、怎么用

1. 把「一键安装并运行.bat」单独复制到一个空文件夹里
   （例如 D:\安全课 或者 桌面新建文件夹），
   不要直接放在下载目录以外的中文长路径里也无所谓，但不要放进
   jiangsu-safety-platform-skip 这个文件夹里面。

2. 双击「一键安装并运行.bat」。

3. 等它自动完成 4 步：
   [1/4] 检查 / 自动安装 Python 3    （装过 Python 会直接跳过）
   [2/4] 检查更新，只在有更新时才下载项目
        （下载到脚本旁边的 jiangsu-safety-platform-skip 文件夹）
   [3/4] 自动安装依赖库 requests
   [4/4] 新开一个窗口运行 main.py

4. 在最后弹出的窗口里，按提示输入：学校名称、账号、密码。
   输入密码时屏幕不会显示字符，这是正常的，输完直接回车。


二、常见问题

Q1: 提示"无法安装 Python 3"
    手动去 https://www.python.org/downloads/ 下载安装 Python 3，
    安装界面最下面勾选 "Add python.exe to PATH"，
    装完之后重新双击本脚本。

Q2: 提示"项目下载失败"
    GitHub 连不上。换个网络（比如开手机热点）再双击本脚本重试一次。
    脚本会自动依次尝试官方地址 + 三个镜像加速地址。

Q3: 杀毒软件报毒 / 拦截
    本项目是开源脚本（Apache 2.0 协议），
    报毒一般是因为脚本会操作网络请求，选择允许即可。

Q4: 想强制重新下载最新版
    两只办法（任选一个）：
    a) 删掉旁边的 jiangsu-safety-platform-skip 文件夹和
       _project_version.txt，再双击本脚本；
    b) 用命令行运行： 一键安装并运行.bat -u
   正常情况下不需要手动做，脚本每次都会自动联网比对版本。

Q5: 以后只想再运行一次
    重新双击本脚本即可。它会自动跳过已装好的 Python、依赖，
    以及没有更新的项目文件，几秒就能进到 main.py。

Q6: 提示"无法检查更新，保留当前已有的版本"
    说明连不上 GitHub（不影响使用），脚本会继续用已有的那份，
    不会删掉它。等网络好了再双击就会正常检查更新。


三、脚本做了什么（透明说明）

- 检测本机有没有 Python 3.8 以上版本；
  没有就从 python.org（失败则换华为云镜像）下载 Python 3.12.10
  并以"仅当前用户、不写注册表全局权限"的方式静默安装，
  安装参数：InstallAllUsers=0 PrependPath=1，不添加右键菜单、不关联文件。
- 联网查询 GitHub 上 main 分支的最新 commit 号（依次尝试
  curl、PowerShell、git ls-remote 三种方式，外加一个镜像地址），
  和脚本旁边的 _project_version.txt 里记录的版本号比对：
    - 一样  -> 提示"本地已是最新版，无需重新下载"，直接跳过
    - 不一样 -> 才删掉旧目录重新下载
    - 查不到 -> 保留现有版本，不会删你的文件
- 需要下载时，从 GitHub 下载 main 分支压缩包，解压到脚本同目录下的
  jiangsu-safety-platform-skip 文件夹，并把版本号记进
  _project_version.txt。
- 按项目自带的 requirements.txt 安装 requests（走清华 PyPI 镜像，
  失败自动回退官方源）。
- 打开项目文件夹，并在新窗口中运行 main.py。
